# Engineering resource catalog

Selected from darktune's 37 public stars and 16 public repositories, inspected 2026-09-14. These are reference links, not installed services. Recheck licenses and current documentation before adoption. Full inventory is in LOOM's docs/workflow/github-inventory.json.

## Architecture and engineering

- [System Design Primer](https://github.com/donnemartin/system-design-primer): compare architecture and scaling tradeoffs; avoid copying large-system patterns into small products.
- [Matt Pocock skills](https://github.com/mattpocock/skills): domain models, deep modules, and architecture review. Four relevant skills installed with their dependencies.
- [Superpowers](https://github.com/obra/superpowers): systematic debugging, test-first development, and verification; selected skills installed rather than the entire orchestration framework.
- [ECC](https://github.com/affaan-m/ECC): selected API, frontend, migration, Postgres, and deployment guidance installed.
- [Build Your Own X](https://github.com/codecrafters-io/build-your-own-x): implementation exercises for understanding unfamiliar systems.
- [Coding Interview University](https://github.com/jwasham/coding-interview-university): computer science study reference.
- [Awesome Scalability](https://github.com/binhnguyennus/awesome-scalability): additional source, not in the inspected stars; real-system scaling case studies.

## Design and web development

- [React](https://github.com/react/react): library source; use official documentation for version-specific APIs.
- [Design Resources for Developers](https://github.com/bradtraversy/design-resources-for-developers): additional source, not in the inspected stars; design inspiration, fonts, icons, and UI resources. Each linked asset has its own license.
- Existing Figma and Vercel plugin skills cover design translation, components, accessibility-related UI decisions, and web delivery. Do not install duplicate copies by default.
- [ArmorPaint](https://github.com/armory3d/armorpaint): 3D material authoring candidate; does not solve garment pattern reconstruction.
- [Godot](https://github.com/godotengine/godot): candidate for a standalone 3D application; not a reason to replace LOOM's browser viewer.

## Data, workflows, and operations

- [Memgraph](https://github.com/memgraph/memgraph): graph-oriented data candidate; verify edition and license before treating every feature as open source.
- Existing Supabase plugin skills and installed postgres-patterns/database-migrations cover relational design and migrations. No database server was installed by this setup.
- [n8n](https://github.com/n8n-io/n8n): workflow automation candidate; inspect its fair-code licensing and deployment requirements.
- [Infisical](https://github.com/Infisical/infisical) and [Phase](https://github.com/phasehq/console): secrets-management candidates; never migrate credentials merely because the repositories are starred.
- [Authelia](https://github.com/authelia/authelia): authentication infrastructure candidate.
- [Katana](https://github.com/projectdiscovery/katana): crawler candidate for explicitly scoped public research; ordinary source lookup should use existing browsing first.
- [The Book of Secret Knowledge](https://github.com/trimstray/the-book-of-secret-knowledge): discover shell and operations tools; verify commands before running them.
- [Public APIs](https://github.com/public-apis/public-apis): discovery index; independently verify availability and pricing.

## Efficiency

- [Caveman](https://github.com/JuliusBrussee/caveman): communication skill installed. Use full intensity by user default; preserve necessary qualifications and prioritize clarity. No CLI, telemetry service, or performance guarantee installed.
- [Caveman Compression](https://github.com/wilpel/caveman-compression): research reference; evaluate retention of negations, numbers, API contracts, and uncertainty before using compression.
- JuliusBrussee/caveman-code is described as frozen; excluded from installation.
